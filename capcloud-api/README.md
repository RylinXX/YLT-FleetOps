# 京城建废 · 综合信息查询

首页为面向日常使用的综合信息查询网站，覆盖用户截图中的六类企业、车辆及场所信息。原接口工作台保留在 `/lab.html`。未包含登录、曝光台、备案或管理操作。

支持区域、关键词、类型、余量上下限、有效期状态、到期日期范围组合筛选；支持临近到期、容量大小、许可车辆数排序；支持详情、关注和筛选结果 CSV 导出。业务口径和数据完整性限制见 `docs/DIRECTORY.md`。

## 启动

需要 Node.js 24 或更高版本，使用内置 SQLite 支持。

```sh
npm install
npm run export
npm run dev
```

访问 http://127.0.0.1:5188 。端口占用时用 `PORT=5189 npm run dev`。

```sh
npm test
npm run build
npm start
```

生产构建仍只监听本机。`npm start` 需要先构建。浏览器不直接请求 HTTP 上游，统一通过同源 `/api/query/:id` 查询。

## 交付文件

- `docs/API.md`：6 项接口的地址、参数、字段差异、调用方式和迁移风险。
- `docs/verification.json`：匿名抽样核验记录，仅保存统计及字段名，不保存真实记录内容。
- `public/exports/capcloud.postman_collection.json`：可导入 Postman 的七项 GET 请求集合。
- `public/exports/openapi.json`：OpenAPI 3.0.3 接口描述，指向原始上游。
- `public/exports/catalog.json`：机器可读接口清单。
- `shared/catalog.mjs`：前后端共用的参数定义、字段映射与请求构造。
- `directory-store.mjs`：独立 SQLite 数据库、增量更新及变更记录。
- `docs/DATABASE.md`：入库规则、持久化位置、数据保留与备份说明。

## 接入你的网站

1. 将 `shared/catalog.mjs` 和 `createApiHandler` 中的白名单转发逻辑整合到自己网站的服务端。
2. 浏览器调用自己网站的同源 `/api/query/companies` 等路径，不直接调用上游。
3. 配置自己网站的身份验证、域名与 Origin 白名单、按用户限流、HTTPS、监控和缓存策略。当前代码仅供本机测试，不能原样作为公开互联网服务。
4. 和平台运营方确认再利用授权与迁移后的正式接口。匿名可访问不等于开放 API 授权或稳定性承诺。

前端没有保存账号或令牌，工作台调用历史在浏览器内存中保留 50 条元数据。源站查询记录保存到独立 SQLite 数据库，本地默认 `data/directory.sqlite`，通过 `DATABASE_PATH` 可以指定位置。用户私有补充字段与源字段分开，不向公共接口返回。JSON 表格统一转义，避免上游文本被当作 HTML 执行。

接口工作台默认每页 10 条，最大 20 条；页码最大 10000；每分钟最多 30 次转发；最多同时 2 个上游请求；15 秒超时；最大响应 2 MiB。这些是本地保护限制，不代表上游能力。

综合查询使用 `/api/datasets/:id`，只读取数据库已有数据。北京时间每日 00:00 自动同步全部六类，或手动刷新当前分类触发后台同步，新增补入、变化更新、缺失留档，失败继续显示原数据。一次来源请求最多 20000 条，响应上限 4 MiB、90 秒超时；普通访问（包括空数据库）不会触发源站请求。筛选排序仍覆盖本库当前可查记录，不仅排序当前页面。来源有重复或数量差异时明确显示警告，不承诺完整性。

开发模式关闭热更新，编辑后刷新页面。当前综合查询预览地址为 http://127.0.0.1:5189 ，启动同端口使用 `PORT=5189 npm run dev`。

`npm run verify:live` 会向七个已确认的查询接口各发起一次匿名请求并刷新核验记录，不批量抓取数据。
