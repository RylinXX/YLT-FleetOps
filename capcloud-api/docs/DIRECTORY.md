# 综合信息查询网站

## 页面

- `/`：综合查询首页，默认打开消纳场与临时处置点。
- `/?category=reuse-sites`：弃土综合利用点。
- 其余分类参数为 `companies`、`vehicles`、`energy-companies`、`energy-vehicles`、`disposal-sites`。
- `/lab.html`：原接口测试工作台。

## 筛选与排序

关键词查询匹配名称、所属/经营单位及地址，不按联系人手机号批量检索。区域及类型下拉选项取当前数据中的实际取值。

容量下限是严格大于：输入 5000 不包含恰好为 5000 的记录。上限是不超过，包含等于。未提供、空串、`null`、无效数值不当作零。消纳场显示吨；综合利用点保留原始数值，不猜测原站未注明的单位。

有效期按北京时间的自然日计算，截止日期当天为“今日到期”，第二天才是“已到期”。提供 7、30、90 天内到期、有效期内、尚未生效、已到期及日期未提供筛选；起止日期过滤包含边界。

“临近到期优先”将未到期记录按到期日由近到远排列，之后为已到期记录，缺失日期最后显示。容量大小排序按数字而非字符串比较，空值在两个方向都排到末尾。

企业接口仅有审批日期，没有可确认的截止日期，因此不提供企业到期筛选；可按许可车辆数和名称排序。

有效期状态只反映日期范围，不等同于审批、冻结、经营状态或行政许可有效性认定。原站登记字段保留在详情中。

## 数据完整性

此前接口测试页只是逐页测试；本网站通过同一分页接口一次请求所选分类最多 20000 条记录，再对结果进行筛选和排序，不只排序屏幕上的 10 条记录。实测车辆一次请求取得全部 12882 条，耗时约 50 秒；来源列表分批读取在较深页会明显变慢，一次性请求可减少总等待时间并避开跨页排序不稳定。查询只读取本库，不触发源站抓取。生产服务北京时间每日 00:00 顺序同步全部六类，手动刷新只同步当前分类。来源总数超过 20000 条时明确报错。

必须区分“读取完成”与“来源完整性可确认”。接口响应字段：

- `complete`：本次读取任务结束，结果可用。
- `coverageComplete`：实际返回数、去重记录数、来源总数一致，且未出现重复标识。
- `quality`：来源总数、原始返回数、去重数、重复行及重复 ID 数。
- `warning`：来源存在数量/标识差异时的显式提示。

实测普通企业列表存在来源统计差异：来源标注 1798 条，某次遍历取得 1796 条，且存在重复 ID；单次读取较大结果也未能消除差异。该情况下页面显示“本次取得/来源标注”及黄色警告，不显示“全量已载入”。所有筛选、统计、排序和导出仅基于本次取得的记录，不能证明未返回的记录不存在。异常来源 CSV 文件名带“来源数据不完整”。

完全重复的记录按原始 JSON 去重；同 ID 不同内容保留并区分行键。若分页中总数发生变化、遇到网络错误、未返回后续页、超时、超量或业务失败，显示错误，不把中间结果当作成功数据。

## 本地存储与部署

关注只在浏览器保存行标识，不保存联系人信息。查询记录不写入服务端磁盘，页面刷新后从服务器短时缓存或上游重载。用户主动导出时仅包含列表业务字段，不含联系人、电话等详情字段，并对 CSV 公式前缀做转义。

服务仅监听本机，保留固定上游白名单、不转发账号凭证。对外部署还需平台数据使用授权、身份验证、HTTPS、用户级限流、审计和来源迁移安排。当前预览不是公开互联网部署。

## 验证

`npm test` 覆盖字段映射、容量边界、北京日期、未知值、临近到期分组、组合筛选、CSV 安全、完整遍历、缓存、原生数量差异及原接口代理保护。

`DIRECTORY_URL=http://127.0.0.1:5189 node scripts/verify-directory.mjs` 会逐类真实读取并核验排序，仅将计数与数据质量信息写到 `directory-verification.json`，不保存真实行内容。它会读取整个分类，数据量高于原 `verify:live` 单条抽样脚本。
